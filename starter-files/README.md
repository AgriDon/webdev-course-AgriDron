## Lección 1: ¿Qué es el desarrollo web?

### Objetivo
Comprobar que una página web es contenido (HTML) más estilo (CSS): cambiar cómo se ve una página sin tocar su contenido.

### Instrucciones

Abre `leccion-1-intro-desarrollo-web/index.html` en tu navegador (o pega el HTML y el CSS en CodePen) y completa los ejercicios de `estilo.css`:

1. Cambia el color de fondo de la página.
2. Cambia el tipo de letra.
3. Cambia el color del título.
4. Cambia el tamaño de la letra del título.
5. Convierte el botón en el del video: rojo, redondeado y con letras blancas.

### Requisitos
- Modificar solo el archivo `estilo.css`.
- No cambiar el texto de `index.html`.

### Resultado esperado
La misma página, con el mismo contenido, pero con un estilo diferente.

## Lección 2: Introducción a HTML

### Objetivo
Crear una primera página web utilizando las etiquetas básicas de HTML.

### Instrucciones

Desarrolla una página web personal que contenga los siguientes elementos:

1. Un título para la página utilizando TITLE.
2. Un encabezado principal utilizando H1.
3. Un párrafo utilizando P para presentarte.
4. Un encabezado secundario utilizando H2.
5. Un párrafo describiendo tus pasatiempos.
6. Una imagen utilizando IMG, SRC y ALT.
7. Un enlace a otra página web utilizando A y HREF.

### Requisitos
- Utilizar la estructura básica de HTML.
- Escribir correctamente las etiquetas de apertura y cierre.
- Utilizar los atributos correspondientes.
- Guardar el archivo con el nombre index.html.

### Resultado esperado
Una página web personal que muestre tu presentación, tus pasatiempos, una imagen y un enlace externo.

## Lección 3: Añadir más elementos HTML

### Objetivo
Aprender a utilizar listas, imágenes y enlaces para enriquecer una página web.

### Instrucciones

Desarrolla una página web sobre tus elementos favoritos.

El ejercicio debe incluir:

1. Un título principal utilizando H1.
2. Un encabezado H2 para tus videojuegos favoritos.
3. Una lista desordenada utilizando UL.
4. Al menos tres elementos utilizando LI.
5. Una imagen utilizando IMG.
6. Los atributos SRC y ALT para la imagen.
7. Un enlace externo utilizando A y HREF.

### Requisitos
- Utilizar correctamente las etiquetas HTML.
- Completar todas las actividades.
- Mantener una estructura organizada.
- Guardar el archivo como index.html.

### Resultado esperado
Una página web que muestre una lista de videojuegos favoritos, una imagen y un enlace externo.

## Lección 4: Introducción a CSS

### Objetivo
Aprender los fundamentos de CSS: selectores, propiedades de color, fuentes, diseño de caja y estados interactivos con `:hover`.

### Instrucciones
Abre la plantilla de `lesson-4/index.html` y completa las reglas en `lesson-4/styles.css` (o usa la plantilla precargada de CodePen):

1. Cambia la tipografía a una fuente limpia (*sans-serif*).
2. Asigna color de fondo a la página y a la tarjeta.
3. Centra la tarjeta con `margin: 0 auto` y dale esquinas redondeadas.
4. Convierte la imagen en un avatar circular con `border-radius: 50%`.
5. Diseña un botón con estilos modernos y efecto interactivo `:hover`.

### Archivos
- `lesson-4/index.html`: estructura semántica de la tarjeta de presentación.
- `lesson-4/styles.css`: plantilla inicial comentada con instrucciones paso a paso.
- `lesson-4-starter.md`: guía didáctica detallada de la lección práctica.

## Lección 5: Página de perfil personal

### Archivos:
- `leccion-5-pagina-web-personal/index.html`: estructura HTML inicial.
- `leccion-5-pagina-web-personal/style.css`: hoja de estilos vacía.

### Cómo comenzar

1. Abre el editor en línea indicado en la práctica de la lección.
2. Coloca el contenido de `index.html` en el archivo HTML del editor.
3. Deja `style.css` vacío.
4. Sigue el video para construir el perfil paso a paso.

No es necesario instalar programas. El ejemplo completo del video está en la carpeta `completed-examples`.
