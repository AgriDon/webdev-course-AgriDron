# Archivos iniciales

Esta carpeta contiene el código de partida de las prácticas del curso.

## Lección 5: Página de perfil personal

Archivos:
- `leccion-5-pagina-web-personal/index.html`: estructura HTML inicial.
- `leccion-5-pagina-web-personal/style.css`: hoja de estilos vacía.

## Cómo comenzar

1. Abre el editor en línea indicado en la práctica de la lección.
2. Coloca el contenido de index.html en el archivo HTML del editor.
3. Deja style.css vacío.
4. Sigue el video para construir el perfil paso a paso.

No es necesario instalar programas.

El ejemplo completo del video está en la carpeta completed-examples.
