# Lección 2: Introducción a HTML

## Objetivo
Crear una primera página web utilizando las etiquetas básicas de HTML.

## Instrucciones

Desarrolla una página web personal que contenga los siguientes elementos:

1. Un título para la página utilizando TITLE.
2. Un encabezado principal utilizando H1.
3. Un párrafo utilizando P para presentarte.
4. Un encabezado secundario utilizando H2.
5. Un párrafo describiendo tus pasatiempos.
6. Una imagen utilizando IMG, SRC y ALT.
7. Un enlace a otra página web utilizando A y HREF.

## Requisitos
- Utilizar la estructura básica de HTML.
- Escribir correctamente las etiquetas de apertura y cierre.
- Utilizar los atributos correspondientes.
- Guardar el archivo con el nombre index.html.

## Resultado esperado
Una página web personal que muestre tu presentación,
tus pasatiempos, una imagen y un enlace externo.
