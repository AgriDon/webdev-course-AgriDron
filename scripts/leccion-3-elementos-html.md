
# Lección 3: Añadir más elementos HTML

## Introducción

Hola chicos, bienvenidos a una nueva lección de HTML.

En la clase anterior aprendimos a crear títulos y párrafos para nuestra página web. Hoy vamos a aprender a agregar listas, imágenes y enlaces.

Así podemos crear una página mucho más divertida e interesante.

## 1. ¿Cómo crear listas en HTML?

Imaginen que quieren hacer una lista de sus videojuegos favoritos, sus juguetes o sus comidas preferidas.

En HTML podemos crear listas fácilmente.

Para hacer una lista utilizamos la etiqueta UL, que crea una lista con puntos, y la etiqueta LI, que representa cada elemento de esa lista.

Por ejemplo, vamos a crear una lista de nuestros videojuegos favoritos.

Primero agregamos un encabezado H2 con el título "Mis videojuegos favoritos".

Después utilizamos la etiqueta UL y, dentro de ella, agregamos diferentes elementos utilizando LI.

Podemos escribir, por ejemplo:
- Mario Kart.
- Roblox.
- Minecraft.

Como pueden observar, estas etiquetas permiten organizar información en forma de lista.

## 2. ¿Cómo agregar imágenes?

También podemos agregar fotografías de nuestras mascotas, dibujos o imágenes favoritas utilizando la etiqueta IMG.

Esta etiqueta utiliza el atributo SRC para indicar dónde se encuentra la imagen y ALT para describirla si no se puede mostrar o si alguien utiliza un lector de pantalla.

Por ejemplo, vamos a agregar un encabezado H2 llamado "Mi mascota favorita".

Ahora utilizamos la etiqueta IMG y agregamos el atributo SRC con la dirección de nuestra imagen.

También agregamos ALT para describir lo que representa.

En este ejemplo podemos utilizar una imagen de prueba.

Si queremos mostrar otra imagen, podemos cambiar la dirección que aparece.

También podemos modificar el ancho de la imagen utilizando el atributo WIDTH.

## 3. ¿Cómo crear enlaces?

Ahora, ¿cómo crear enlaces?

¿Alguna vez han hecho clic en una palabra y han llegado a otra página web?

Eso es un enlace.

Para crear enlaces utilizamos la etiqueta A y el atributo HREF, que indica a qué dirección queremos ir.

Por ejemplo, podemos crear un enlace hacia Google.

Dentro de la etiqueta A escribimos el texto que queremos mostrar y en HREF colocamos la dirección de la página web.

De esta manera, cuando alguien haga clic en el texto, podrá acceder a la página indicada.

## 4. Actividad práctica

Ahora es momento de poner en práctica lo aprendido.

Vamos a crear una página web que contenga:

1. Un título principal.
2. Una lista de videojuegos favoritos.
3. Una imagen de una mascota, dibujo o personaje favorito.
4. Un texto alternativo para la imagen.
5. Un enlace hacia una página web externa.

Utilizaremos las etiquetas UL, LI, IMG y A, junto con sus respectivos atributos.
