
Hola chicos, bienvenidos. Hoy vamos a aprender a crear nuestra primera página web usando HTML.

¿Alguna vez han visitado YouTube, un videojuego en línea o una página para ver dibujos? Todas esas páginas utilizan tecnología que permite mostrar textos, imágenes y muchas otras cosas más.

Hoy aprenderemos a crear nuestra propia página web desde cero.

¿Qué es HTML? Pues HTML, por así decirlo, es un lenguaje, pero no es un lenguaje de programación. Lo utilizamos para organizar el contenido de una página web. La estructura, en pocas palabras, es el esqueleto de nuestra página web.

Por ejemplo, nos permite colocar textos, títulos, párrafos, imágenes y enlaces.

Imaginen que una página web es como una casa. HTML sería la estructura de la casa. Nos ayuda a decidir dónde van las habitaciones, las puertas y las ventanas.

Para crear una página web utilizamos etiquetas. Las etiquetas son palabras especiales que escribimos entre los símbolos menor que y mayor que.

Por ejemplo, tenemos la etiqueta TITLE, que prácticamente nos da el título, pero también podemos tener etiquetas como H1, que sirven para los encabezados.

Se comienza con etiquetas de apertura. Primero se abre y después se cierra. Entre esas dos etiquetas se escribe el contenido que queremos mostrar.

Como, por ejemplo, "Mi primera página web". Prácticamente, se muestra información.

¿Cuál es la diferencia entre TITLE y H1?

TITLE es como el nombre que se quiere mostrar en la pestaña del navegador o en los resultados del buscador.

H1 también tiene relación con las búsquedas y el SEO. Por ejemplo, es recomendable que tengan solamente un H1 principal en sus páginas web.

Porque, al hacer una búsqueda de su página web, el buscador de Google se va a guiar, entre otros factores, por el contenido de los encabezados que tenga en su página web.
