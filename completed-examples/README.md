# Ejemplos terminados

Esta carpeta contiene las soluciones completas de las prácticas del curso.

## Lección 5: Página de perfil personal

El ejemplo incluye:
- Fotografía de muestra.
- Nombre y presentación ficticios.
- Lista de pasatiempos.
- Enlaces educativos.
- Pie de página.
- Estilos de colores, espacios y fotografía circular.

## Cómo utilizarlo

Abre el editor en línea de la práctica y coloca el contenido de
index.html y style.css en sus archivos correspondientes.

Compara este resultado con tu práctica para revisar diferencias
y corregir errores.

Los archivos de partida están en la carpeta starter-files.
